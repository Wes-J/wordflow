# Vocabulary data sources

## IELTS-oriented academic vocabulary

The starter deck **雅思学术核心（NAWL）** contains 66 selected headwords taken from the New Academic Word List (NAWL 1.2), by Charles Browne and Brent Culligan (2013). NAWL is a list for general academic English, not an official IELTS vocabulary list. Its source list contains 957 items and is released under CC BY-SA 4.0 by the New General Service List Project.

- Project and license information: https://www.newgeneralservicelist.com/new-academic-word-list
- Source word list: https://www.newgeneralservicelist.com/s/NAWL_12_alphabetized_description.txt
- License: https://creativecommons.org/licenses/by-sa/4.0/

Changes made here: 66 headwords were selected from the source list, given concise Chinese glosses, and paired with newly written example sentences. These annotations and the adapted NAWL subset are shared under CC BY-SA 4.0. Attribution: Browne and Culligan, *The New Academic Word List* (NAWL 1.2), 2013; New General Service List Project. The full NAWL wordlist is not bundled; the app includes a curated subset rather than claiming to provide all 957 entries.

## English roots

The root deck includes the 1,061-entry dataset from **WithEnglishWeCan/generated-english-roots-list**. The source provides English roots, concise English glosses, and example words. Its repository states that it is licensed under MIT.

- Project and source data: https://github.com/WithEnglishWeCan/generated-english-roots-list
- License: MIT, as stated in the repository README.

Changes made here: bracketed root forms and source grading annotations on example words were removed for display; English glosses and the remaining examples are kept from the dataset. Root types are labeled as prefix/suffix only where the source marks them as such; other entries are labeled as roots.

## Prefixes and suffixes

The prefix and suffix deck is derived from Colin Goldberg's **morphemes** project, which provides English morphemes, meanings, and examples in structured form. The app includes 3,758 distinct prefix/suffix records from that source, alongside the 1,061-entry root list above.

- Project: https://github.com/colingoldberg/morphemes
- License: MIT (Copyright 2019 Colin Goldberg)

Changes made here: prefix/suffix labels were translated to Chinese and duplicate forms were collapsed by spelling and type. The original English glosses and examples are retained. The original MIT notice is included below.
